CAN 메시지셋

ID방향내용
0x100WS → 펌프SET_RATE (rate, vtbi, drug_id, weight)
0x101WS → 펌프ALARM_ACK / SILENCE
0x110WS → 펌프PUMP_CONTROL (start/stop/bolus/dump)
0x120WS → 펌프AUTH_REQUEST
0x130WS → 펌프DEBUG_CMD (서비스 콘솔, 64바이트/8프레임)
0x140WS → 펌프FW_UPDATE (청크 56바이트/7프레임)
0x200펌프 → WSTELEMETRY (rate, infused, remaining, batt, alarm)
0x201펌프 → WSALARM_EVENT
0x202펌프 → WSSTATUS (state, auth, ders, bypass)
0x203펌프 → WSDEBUG_RESPONSE (ASCII, 이어붙임)
0x300펌프 → WSMEMORY_DUMP
