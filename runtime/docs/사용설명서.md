# CANnula Clinical Workstation — 사용설명서

> ⚠ 이 소프트웨어는 **교육·시연용 예시 앱**입니다. 실제 환자 치료에 사용할 수
> 없습니다.

## 1. 시작하기

1. 바탕화면의 **CANnula Workstation (WEAK)** 아이콘을 실행합니다.
2. 프로그램이 CAN 게이트웨이를 자동으로 띄우고 연결합니다. 상단 배지가
   **게이트웨이 연결** 로 바뀌면 준비된 상태입니다.
3. 병동에서 배정받은 계정으로 로그인합니다.

| 역할 | 쓸 수 있는 화면 |
|---|---|
| 간호사 (nurse) | 대시보드, 알람, 주입 설정, 환자 정보, 이벤트 로그, 설정 |
| 기사 (tech) | 위 + 진단·CAN 콘솔, 펌웨어 전송 |
| 관리자 (admin) | 전부 |

## 2. 펌프 연결

**설정** 화면에서 펌프에 닿는 방법을 고릅니다.

| 방식 | 언제 쓰나 |
|---|---|
| 시뮬레이터 | 교육·시연. 실제 펌프 없이 화면을 익힐 때 |
| USB-CAN 어댑터 (slcan) | 실제 펌프 연결. 어댑터가 잡힌 COM 포트를 적습니다 |
| 가상 CAN (UDP) | 랩 구성 |

비트레이트는 펌프 설정과 같아야 합니다 (기본 500 kbps).
연결이 끊기면 **게이트웨이 재시작** 을 누릅니다.

## 3. 주입 시작하기

1. **환자 정보** 화면에서 배정 환자를 입력하고 저장합니다.
   저장한 체중이 주입 설정에 자동으로 반영됩니다.
2. **주입 설정** 화면에서
   - 약물을 고릅니다
   - 주입 속도(mL/h)와 총 주입량(VTBI, mL)을 입력합니다
   - 계산 결과(mg/h, mcg/kg/min, 예상 소요 시간)를 확인합니다
   - 가드레일 판정을 확인합니다
3. **펌프로 전송** 을 누릅니다.
4. **대시보드** 로 돌아가 **주입 시작** 을 누릅니다.

### 가드레일 (DERS)

| 판정 | 뜻 | 조치 |
|---|---|---|
| 통과 | 상한 안 | 그대로 진행 |
| 경고 상한 초과 | 흔치 않은 용량 | 처방을 다시 확인 |
| 절대 상한 초과 | 허용 범위 밖 | 기사용 해제 코드 필요 |

절대 상한을 넘기는 처방은 **서비스 기사 입회 하에만** 진행합니다.
해제 코드는 서비스 매뉴얼에 있습니다.

## 4. 알람 대응

알람이 발생하면 대시보드 상단에 붉은 배너가 뜹니다.

| 알람 | 확인할 것 |
|---|---|
| 폐색 | 라인 꺾임, 필터, 카테터 |
| 공기 감지 | 라인 프라이밍 상태 |
| 배터리 부족 | 전원 어댑터 연결 |
| 주입 완료 / 저장통 비었음 | 잔량, 세트 교체 |
| 용량 상한 초과 | 처방 재확인 |
| 유량 오류 | 세트 재장착 |

**알람** 화면에서 **현재 알람 확인** 을 누르면 펌프에 무음화 요청을 보냅니다.
알람의 원인을 해결하기 전에 무음화하지 마십시오.

## 5. 볼루스

대시보드 오른쪽 아래에서 용량(mL)을 입력하고 **볼루스 주입** 을 누릅니다.
고위험 약물의 볼루스는 처방에 명시된 경우에만 사용합니다.

## 6. 이벤트 로그

**이벤트 로그** 화면에 이 세션에서 일어난 일이 시간순으로 남습니다.
**CSV 저장** 을 누르면 펌프별 파일로 저장됩니다. 파일 이름은 연결된 펌프의
식별자로 자동 지정되며, 필요하면 직접 바꿀 수 있습니다.

저장된 파일에는 환자 정보가 포함됩니다. 취급에 주의하십시오.

## 7. 펌웨어 전송 (기사용)

⚠ 전송 중에는 주입이 멈추고 안전 기능이 해제됩니다.
**반드시 환자에게서 라인을 분리한 뒤** 진행하십시오.

1. **펌웨어 전송** 화면에서 설치된 이미지를 고르거나 파일을 선택합니다.
2. 파일 정보(크기·청크 수·체크섬)를 확인합니다.
3. **펌프로 전송** 을 누릅니다. 진행률이 끝까지 갈 때까지 전원을 끊지 마십시오.
4. 전송이 끝나면 펌프를 재시작하고, 진단 화면에서 `ver` 로 버전을 확인합니다.

## 8. 진단 (기사용)

**진단 · CAN 콘솔** 화면에서:

- **서비스 명령** — 펌프의 서비스 콘솔에 명령을 보냅니다
  (`id`, `ver`, `help`, `get`, `set <항목> <값>`)
- **메모리 조회** — 주소와 길이를 지정해 펌프 메모리를 읽습니다
- **원시 프레임 전송** — CAN ID·DLC·데이터를 직접 지정해 보냅니다
- **시스템 진단 도구** — 등록된 진단 명령을 실행합니다
- **버스 트래픽** — 흐르는 프레임을 실시간으로 봅니다. ID 필터를 쓸 수 있습니다

## 9. 문제 해결

| 증상 | 확인 |
|---|---|
| 게이트웨이 끊김 | 설정 → 게이트웨이 재시작. 방화벽이 47100 포트를 막지 않는지 |
| 텔레메트리가 안 옴 | 비트레이트, 버스 종단(120Ω), 어댑터 COM 포트 |
| 잔량이 이상한 값 | 펌프에 VTBI 를 다시 전송한 뒤 확인 |
| 표시 속도와 지시 속도가 다름 | 펌프가 아직 새 지시를 반영하지 않았을 수 있습니다. 그래도 다르면 **즉시 주입을 정지하고 기사에게 연락하십시오** |
| 로그가 저장되지 않음 | 설정 화면의 로그 폴더 경로와 쓰기 권한 |

## 10. 지원

기술 지원: 병원 의공학팀 → 공급사 서비스 데스크
소프트웨어 버전은 **정보** 화면에서 확인합니다.
