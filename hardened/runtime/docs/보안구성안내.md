# CANnula Clinical Workstation — 보안 구성 안내 (v0.0.2)

의공학팀·IT 담당자를 위한 설치·운영 안내입니다.

## 1. 설치

- 설치 파일은 **관리자 권한**으로 실행합니다 (Program Files 아래에 설치됩니다).
- 설치 경로를 사용자가 쓸 수 있는 폴더로 바꾸지 마십시오. 확장(`plugins\`)과
  게이트웨이(`bin\`)가 있는 폴더에 쓰기 권한이 있으면 임의 코드 실행 위험이
  생깁니다.
- 설치 직후 첫 실행에서 `config\cannula.key`(CAN 인증 키)가 생성됩니다.
  이 파일은 백업 대상이며, 유출 시 즉시 재발급(파일 삭제 후 재실행)해야 합니다.

## 2. 계정

- 계정은 `config\cannula.ini` 의 `[users]` 에 **scrypt 해시**로만 저장됩니다.
  평문 비밀번호는 어디에도 남지 않습니다.
- 역할과 권한:

  | 역할 | 레벨 | 할 수 있는 일 |
  |---|---|---|
  | `nurse` | 1 | 모니터링, 처방 전송, 알람 확인, 환자 정보, 로그 |
  | `tech` / `admin` | 2 | 위 + 진단, 장치 서비스 명령, 소프트웨어 업데이트 |

- 해시 생성은 배포 담당자가 수행합니다. 공용 계정은 쓰지 말고 담당자별로
  발급하십시오.
- 로그인 5회 실패 시 해당 사용자는 60초 잠깁니다.

## 3. 네트워크

- 게이트웨이 제어 포트는 **127.0.0.1 에만** 열립니다. 외부에서 접속할 수 없고,
  설정으로 넓힐 수도 없습니다.
- 접속에는 앱이 기동할 때 만드는 1회용 토큰이 필요합니다. 토큰은 디스크에
  기록되지 않습니다.
- 업데이트 서버는 **HTTPS 만** 허용합니다. 인증서를 검증하며, 자체서명
  인증서는 거부됩니다.

## 4. 확장 (plugins)

- `plugins\*.js` 는 같은 이름의 `.sig`(Ed25519 분리 서명)가 있고, 그 서명이
  `config\trusted-keys.json` 의 공개키로 검증될 때만 로드됩니다.
- 서명이 없거나 맞지 않으면 로드하지 않고 **설정 화면에 "거부"** 로 표시됩니다.
  이 표시가 보이면 배포 경로가 오염됐을 수 있으므로 확인이 필요합니다.

## 5. 로그

- 로그 폴더는 `0700`, 파일은 `0600` 권한으로 만들어집니다.
- 자격증명·토큰·키 패턴은 기록 전에 삭제되고, 환자는 **가명 식별자**로만
  남습니다.
- CSV 내보내기 파일 이름은 앱이 정합니다 (장치나 사용자가 경로에 관여할 수
  없습니다).

## 6. CAN 통신

- 워크스테이션은 **인증된 프레임(CANnula-SEC v1)만** 받아들입니다.
  시퀀스 번호, 타임스탬프(30초 창), HMAC-SHA256 을 모두 확인합니다.
- 대시보드의 **프레임 인증** 블록에서 통과·MAC 불일치·리플레이·신선도 초과·
  비인증 폐기 수를 볼 수 있습니다.
- **MAC 불일치나 리플레이 수가 증가하면 버스에 비인가 발신자가 있다는 뜻입니다.**
  즉시 의공학팀에 보고하십시오.
- 구형 펌프(v0.0.1 이하)는 평문 프레임을 보내므로 통신되지 않습니다.
  펌프 펌웨어를 v0.0.2 이상으로 올려야 합니다.

## 7. 가드레일

- 절대 상한(500 mL/h)과 경고 상한(200 mL/h)은 **빌드에 고정**되어 있습니다.
  설정이나 실행 중 조작으로 넓힐 수 없습니다. 임상 한계 변경은 재빌드와
  재검증 절차를 거칩니다.
- 대시보드의 **안전 상태 무결성**이 "실패" 로 표시되면, 프로세스 메모리가 외부에서
  변경된 것입니다. 이 경우 앱은 가드레일을 켜고 권한을 0으로 떨어뜨립니다.
  주입을 정지하고 워크스테이션을 재시작한 뒤 보안 담당자에게 보고하십시오.

## 8. 점검 항목 (월 1회 권장)

- [ ] 설정 화면의 확장 목록에 "거부" 항목이 없는지
- [ ] 대시보드의 MAC 불일치·리플레이 수가 0인지
- [ ] 안전 상태 무결성이 "정상" 인지
- [ ] 로그 폴더 권한이 유지되는지
- [ ] 업데이트 서버 주소가 HTTPS 인지
- [ ] 설치 폴더에 표준 사용자 쓰기 권한이 없는지
